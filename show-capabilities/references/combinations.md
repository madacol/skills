# Combinations

Use when the user asks for stronger ideas. Each combo should create a named output.

| Combine | Use it for | Output |
|---|---|---|
| Browser clerk + evidence reconciler | Government, vendor, insurance, school, immigration, procurement portals. | Submission packet: filled fields, attached proof, missing info, handoff point. |
| Batch worker + artifact factory | Receipts, screenshots, media, exports, scanned forms. | File factory: clean folder, spreadsheet index, ZIP, exception list. |
| Review board + launch room | Product release, event, grant, vendor choice, public announcement. | Go/no-go room: risk review, final checklist, approval list. |
| Local knowledge miner + SOP distiller | Messy old folders, inherited process, team handoff. | Operating manual built from actual past work. |
| CI detective + runbook executor | Broken deploy, failed import, rejected form, failed payroll, broken automation. | Failure packet: reproduction, root cause, fix path, proof check. |
| Monitor + reconciler | Vendor terms, grant portals, dependencies, pricing pages, policy docs. | Change report: what changed, why it matters, what to do. |
| Simulator + eval factory | Sales calls, interviews, support QA, tutoring, negotiation. | Practice loop: rubric, scored attempts, improvement plan. |
| Workspace operator + human gate | Ongoing admin/business/project support. | Private ops room: prepared work, tracked state, explicit approval points. |

## Transfer moves

- Failed CI → failed invoice import.
- PR review → contract/vendor review.
- Release checklist → event/grant/submission checklist.
- Test suite → QA rubric.
- Code migration → folder/tool/vendor migration.

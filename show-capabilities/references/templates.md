# Templates

Use when the user asks for a ready answer.

## Short

```text
You can hand me messy work materials and ask for a checked result.

Examples:
- Folder of docs → clean packet, index, missing-items list.
- Website/portal task → prepared draft, downloaded proof, handoff before submit/payment/signature.
- Code repo or failing build → root cause, patch or fix plan, test evidence.
- Receipts/exports/invoices → reconciliation report and clean spreadsheet.
- Risky decision → separate reviewer lenses and go/no-go memo.
- Repeated workflow → SOP, checklist, templates, or reusable skill.

Send a folder, repo, spreadsheet, screenshots, website task, or messy process and ask for the concrete result you want.
```

## Extended

```text
Useful ways to use me:

1. Organize a workbench: files, folders, trackers, docs, decisions, next actions.
2. Process a batch: many files/rows/images/messages → clean output + exception list.
3. Reconcile evidence: invoices/export/receipts/logs/docs → mismatch report.
4. Operate a browser task: fill/extract/download → stop at submit/payment/signature.
5. Review from multiple lenses: finance/legal/security/customer/ops → go/no-go memo.
6. Execute a runbook: follow steps, record proof, pause at gates.
7. Make a repeatable system: SOP, checklist, templates, reminders, skill.

Good prompt:
“I have <materials>. Turn them into <output>. Verify the result and ask before <sensitive action>.”
```

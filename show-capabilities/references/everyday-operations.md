# Everyday And Operations

Use when the user wants practical examples outside a code repo.

| User has | Ask me to | Output |
|---|---|---|
| Immigration/tax/insurance folder | “Build my document room.” | Indexed folder, deadlines, missing docs, question list. |
| Invoices, receipts, bank export | “Reconcile this.” | Mismatch report, clean ledger, items needing approval. |
| Supplier/order/staffing messages | “Run morning ops.” | Today’s risks, supplier status, owner actions. |
| Angry customer/ticket thread | “Build escalation packet.” | Timeline, evidence, likely cause, response draft. |
| Compliance requirements | “Make evidence binder.” | Requirement → proof map, missing evidence, expiry dates. |
| Vendor onboarding portal | “Prepare the submission.” | Filled draft, files attached, missing info, handoff. |
| Grant opportunity | “Check fit and assemble packet.” | Eligibility answer, evidence matrix, draft materials. |
| Event/fundraiser/campaign | “Run launch room.” | Budget, owners, procurement list, risks, daily status. |
| Research question + sources | “Run research desk.” | Source matrix, agreements, conflicts, memo. |
| Community incident reports | “Run incident desk.” | Dedupe, map/list, status board, update draft. |
| School/family admin messages | “Make weekly family plan.” | Dates, forms, errands, reminders, missing info. |
| Skill to practice | “Run a scored practice loop.” | Questions, score, weak spots, next drill. |

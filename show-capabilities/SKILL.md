# Show Capabilities

## Purpose

Help a new user see what to hand over and what result to ask for. Use concrete examples: documents, folders, websites, repos, spreadsheets, screenshots, messages, trackers, and recurring tasks.

## Answer shape

For a broad “what can you do?” request:

1. Start with this framing in plain language:
   - “You can use me for work that has materials, steps, tools, and a result we can check.”
2. State that available actions depend on the enabled tools, connected apps, workspace access, and approval settings in the current chat.
3. Give 6-10 concrete input → output examples.
4. Include 2-4 useful combinations.
5. End by inviting the user to send a real workbench:
   - “Send me a folder, repo, spreadsheet, screenshot batch, website task, or messy process, and I’ll turn it into a concrete next result.”

## Fast example set

Use these when the user wants a compact answer.

| If you have... | Ask me to... |
|---|---|
| A messy folder of documents | Organize it, create an index, find missing items, and produce a clean package. |
| A website or portal task | Gather requirements, fill what can be filled, download proof, and stop at submit/payment/signature. |
| A code repo or failing build | Inspect logs/files, reproduce the issue, make or propose a fix, and run verification. |
| Many files, images, receipts, or exports | Batch process them, verify counts, create a spreadsheet/index, and package the output. |
| A decision with risk | Run separate reviewer lenses, compare tradeoffs, and produce a go/no-go memo. |
| A repeated workflow | Turn it into a checklist, SOP, templates, reminders, or a reusable skill. |
| A customer, ops, or incident problem | Gather evidence, reconstruct what happened, draft the response, and list approvals needed. |
| A launch, event, or project | Maintain the project room: owners, files, budget, risks, decisions, status, and next actions. |
